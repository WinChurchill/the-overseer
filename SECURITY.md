# Security reporting

There is no public release yet. No version is presently certified for public use.
Security fixes will target the latest qualified release; release notes will identify
versions affected and the fixed version.

**Private qualification:** report a suspected issue directly in the existing private
handoff to Winston. Do not open a public issue containing sensitive details.

**Before publication:** enable GitHub private vulnerability reporting on the chosen
repository and verify its **Security → Report a vulnerability** route. The prepared
website builder requires a repository URL and links to that private reporting form.
Publication is blocked until the route actually works. No email or reporting service
is invented here. Until then, no public private-report address is available.

Describe the affected version/hash, impact, minimal reproduction and relevant reason
codes. Use synthetic data and redact credentials/personal information. The maintainer
will acknowledge and coordinate fixes privately; no response-time guarantee is made.

OVERSEER is read-only toward harness execution. Optional network TTS and local data
are explained in PRIVACY.md. Read-only operation does not replace review of the files,
settings and local runtime that a bridge uses.
